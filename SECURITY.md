# Security

To report a security issue in the WEIR AI MCP server, API or website, email **security@weir.ai**.

Please do not open a public GitHub issue for security reports.

- Contact and policy: <https://weir.ai/.well-known/security.txt>
- Terms: <https://weir.ai/terms>

This repository contains documentation and metadata only. The server is hosted by WEIR AI; there is no server code here to patch.
